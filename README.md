## Currently Building

These are active/in-progress systems, intentionally listed as builds in motion rather than finished claims.

### PayFlow - Payment Processing Platform
Full-stack payment platform where every transaction becomes a job with state, retries, idempotency, and audit trails.

- JWT auth, RBAC, customer/admin/operations roles
- Redis-backed queue engine with retry and dead-letter handling
- PostgreSQL accounts, transactions, job history, and audit trail
- React dashboard with live transaction feed and worker/queue status
- Dockerized multi-service setup

### Nexus - Distributed Task Orchestration Engine
DAG-based workflow orchestration engine for dependency-aware task execution.

- Workflow DAG definition, topological sort, cycle detection, critical path
- C++ core module called from Node.js through N-API
- Redis leader election and distributed locking
- PostgreSQL workflow/task state persistence
- Crash recovery, retries, cancellation, and tracing

### Kestrel - Distributed Inference Gateway
AI infrastructure layer for serving model inference reliably.

- Request queueing, dynamic batching, and worker load balancing
- Python/FastAPI model workers with ONNX Runtime
- Circuit breaker, input hash caching, sync/async inference modes
- Prometheus-style metrics for latency, throughput, batch size, and worker utilization
